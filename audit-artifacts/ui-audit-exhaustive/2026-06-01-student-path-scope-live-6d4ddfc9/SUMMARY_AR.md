## ما تم التحقق منه
- لوحة الطالب فتحت بدون شاشة دخول وبدون أخطاء console/network.
- صفحة المسار والمادة فتحت وعرضت رحلة التعلم.
- صفحة الدورة فتحت كمساحة تصفح، مع إبقاء المحتوى غير المفتوح خلف الاشتراك.
- اختبار تدريبي مرتبط بالمسار فتح ويعمل.
- صفحة محاولاتي تعرض الاختبارات ومحاولات الطالب.
- التقارير فتحت للطالب بدون تسريب أو أخطاء.
- صفحة خطتي فتحت وفيها المهام والضوابط.
