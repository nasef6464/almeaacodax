# تقرير FIX-8 — Certificate Professional Design
التاريخ: 2026-05-21
الحالة: Programmatically Closed

## الهدف
رفع جودة صفحة الشهادة لتكون مناسبة للمشاركة والطباعة الرسمية، مع إبقاء التحقق عبر QR محلي.

## ما تم تنفيذه
1. إعادة تصميم صفحة الشهادة بالكامل:
   - Header بتدرج لوني ذهبي/أخضر.
   - إبراز اسم الطالب بخط كبير.
   - إبراز اسم الدورة في بطاقة واضحة.
   - إظهار تاريخ الإصدار ونسبة الإتمام.
   - إضافة نص التحقق الرسمي.
   - QR محلي عبر `QRCodeSVG` في زاوية مخصصة.
2. تحسين الطباعة:
   - إضافة CSS خاص `@media print` لإظهار الشهادة فقط أثناء الطباعة.
3. إجراءات مشاركة/استخدام:
   - زر `طباعة / حفظ PDF`.
   - زر `نسخ رابط التحقق`.
4. إضافة معاينة سريعة للشهادة في لوحة الطالب:
   - داخل بطاقة "شهاداتي" في `Dashboard` تم عرض آخر شهادة مع زر `معاينة`.

## الملفات المعدلة
