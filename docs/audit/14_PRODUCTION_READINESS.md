## 3. المتطلبات القبلية لإطلاق الإنتاج (Prerequisites for Launch)
1. **تجهيز خادم افتراضي مستقل (Dedicated VPS):**
   - ترقية الاستضافة إلى خادم سحابي مستقل (مثل خادم مجاني مدى الحياة من Oracle Cloud أو سيرفر من Hetzner أو DigitalOcean أو Koyeb).
   - هذا يمنع انقطاع الخدمة بسبب سقف الباندويث المجاني (5GB) الذي تفرضه منصة Render.
2. **ضبط المتغيرات البيئية الإنتاجية (`.env.production`):**
   - توليد مفاتيح عشوائية آمنة لـ `JWT_SECRET` و `SESSION_SECRET` و `CSRF_SECRET`.
   - تحديد نطاق الموقع الفعلي في `CORS_ORIGIN` لحظر أي نطاقات أخرى.
3. **شهادة أمان وتشفير النطاق (SSL / HTTPS):**
   - تثبيت شهادة Let's Encrypt مجانية وتفعيل إعادة التوجيه التلقائي إلى HTTPS.
4. **تفعيل النسخ الاحتياطي التلقائي (Automated Database Backups):**
   - جدولة نسخ احتياطي يومي لقاعدة البيانات عبر MongoDB Atlas Backups لضمان حماية بيانات الطلاب والامتحانات.
