## 1. التدقيق الأمني للمصادقة والجلسات (Authentication & Session Security)
- **ملفات تعريف الارتباط (Cookies):** الرموز الأمنية المشفرة (JWT) تُحفظ حصراً داخل ملفات تعريف ارتباط مزودة بخاصية `HttpOnly` و `SameSite=Lax`، مما يجعل قراءتها عبر نصوص JavaScript الخبيثة أمراً مستحيلاً.
- **تشفير كلمات المرور:** استخدام خوارزمية `bcryptjs` مع معامل صعوبة أمان قياسي (Salt Rounds = 10).
- **إلغاء الجلسات عند التحديث الأمني:** عند تغيير تفعيل المستخدم (`isActive: false` أو تغيير كلمة المرور)، يتم إبطال وإلغاء صلاحية كافة الجلسات السابقة فوراً في قاعدة البيانات لمنع استغلال الرموز القديمة.
- **حماية CSRF:** تفعيل تدفق التحقق المزدوج من رمز الحماية (CSRF Token Validation) في كافة طلبات التعديل (`POST`, `PUT`, `PATCH`, `DELETE`).
