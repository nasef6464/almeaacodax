# دفعة مقفولة: Pagination حقيقي لطلبات الدفع (إدارة) — 2026-05-14

## الهدف
تسريع تبويب طلبات الدفع وتحسينه للبيانات الكبيرة، بدل الاعتماد على تحميل واسع ثم فلترة محلية فقط.

## ما تم
1. نقل تحميل طلبات الدفع إلى **فلترة/بحث/صفحات من السيرفر**:
   - `status`
   - `search`
   - `page`
   - `limit=50`
2. إضافة حالة تحميل مخصصة للطلبات داخل الإدارة.
3. إضافة بيانات pagination في الواجهة:
   - إجمالي الطلبات
   - الصفحة الحالية
   - عدد الصفحات
   - أزرار السابق/التالي
4. بعد اعتماد/رفض طلب:
   - تحديث ملخص العدادات
   - إعادة تحميل الصفحة الحالية من الطلبات لضمان دقة الحالة.
