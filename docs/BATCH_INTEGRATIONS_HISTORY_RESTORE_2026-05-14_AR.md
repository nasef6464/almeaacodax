# تقرير دفعة: سجل تغييرات التكاملات والاسترجاع

التاريخ: 2026-05-14  
الحالة: **مقفول برمجيًا** (تم التنفيذ والاختبار المحلي)، ويحتاج رفع/تحقق إنتاجي نهائي.

## ما تم تنفيذه

1. إضافة نموذج سجل تغييرات التكاملات:
   - `server/src/models/PlatformIntegrationHistory.ts`
   - حفظ snapshot كامل قبل كل تعديل على إعدادات التكاملات.

2. تطوير API إدارة السجل والاسترجاع:
   - `GET /api/content/platform-integrations/history`
   - `POST /api/content/platform-integrations/history/:id/restore`
   - حفظ snapshot تلقائي قبل أي `PATCH` على إعدادات التكاملات.

3. تطوير واجهة مدير التكاملات:
   - `dashboards/admin/PlatformIntegrationsManager.tsx`
   - إضافة قسم "سجل تغييرات التكاملات".
   - زر تحديث السجل.
   - زر استرجاع أي نسخة سابقة.
   - بعد الحفظ أو الاسترجاع يتم تحديث الجاهزية + السجل تلقائيًا.

4. ربط خدمات الواجهة مع API:
   - `services/api.ts`
   - `getPlatformIntegrationsHistory`
   - `restorePlatformIntegrationsHistory`

## الفحوص المنفذة

- `npm run typecheck` ✅
- `npm --prefix server run build` ✅

## ملاحظات تشغيلية

- هذه الدفعة لا تغيّر شكل الموقع العام، فقط توسعة عملية داخل لوحة المدير.
- الاسترجاع يعيد إعدادات التكاملات نفسها، ولا يلمس بيانات الطلاب أو المحتوى التعليمي.

## المطلوب قبل إعلان "مقفول نهائيًا إنتاجيًا"

1. رفع التغييرات إلى الفرع الإنتاجي.
2. فحص بصري من لوحة المدير على Vercel:
   - فتح تبويب التكاملات.
   - التأكد من ظهور السجل.
   - تنفيذ استرجاع نسخة والتأكد من تطبيق القيم بعد الحفظ.
