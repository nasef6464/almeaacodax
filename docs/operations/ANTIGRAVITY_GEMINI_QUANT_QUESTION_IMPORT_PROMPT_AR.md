# Prompt تشغيلي — Antigravity / Gemini — إعادة إدخال بنك أسئلة القدرات الكمي

استخدم هذا النص كتعليمات تشغيل للمستورد. المرجع التقني الكامل:
`docs/architecture/QUESTION_BANK_V2_INGESTION_CONTRACT_AR.md`.

## المهمة

أعد إدخال أسئلة كتابي:
- التأسيس الكمي — `documentCode=FND26`
- التجميعات 2026–2027 — `documentCode=COL2627`

إلى بنك أسئلة ALMEAA بصورة نظيفة، مع صورة عالية الجودة لكل سؤال وسياق كامل للذكاء الاصطناعي.

## ممنوعات

- ممنوع إنشاء Path أو Subject أو Section أو Skill أو SubSkill جديد.
- ممنوع تخمين Skill ID غير موجود.
- ممنوع اعتماد OCR/PDF text وحده في الأسس والجذور والكسور والرسومات.
- ممنوع وضع الحل أو الإجابة الصحيحة داخل `aiContext.readableText` أو `speechText` أو `visualDescription`.
- ممنوع تخزين الصور Base64 داخل MongoDB.
- ممنوع تغيير `questionCode` بعد إنشاء السؤال.
- ممنوع اعتماد سؤال عند وجود تعارض بين الصورة، الحل، ومفتاح الإجابات؛ اجعله للمراجعة.
- ممنوع حذف الأسئلة القديمة أو الاختبارات القديمة أثناء الـPilot.

## مصدر الحقيقة

1. الصورة المرئية للصفحة هي المرجع الأول للرياضيات والتنسيق.
2. النص المستخرج من PDF مساعد فقط.
3. الحل ومفتاح الإجابات في المصدر يستخدمان للتحقق من `correctOptionIndex`.
4. الـtaxonomy الحالية في المنصة هي المرجع الوحيد للمهارات.

## هوية السؤال

أنشئ كودًا ثابتًا:

`QDR-QNT-{DOCUMENT_CODE}-P{PAGE_3}-Q{QUESTION_2}`

مثال:
`QDR-QNT-FND26-P015-Q01`

إذا لم يوجد رقم سؤال واضح:
`QDR-QNT-{DOCUMENT_CODE}-P{PAGE_3}-C{CROP_2}`

الكود لا يتغير عند تعديل الصورة أو النص أو الإجابة أو الفيديو.

## الصورة

- قص السؤال كاملًا مع كل ما يحتاجه الطالب للحل.
- لا تقص جزءًا من جذر أو أس أو جدول أو رسم أو اختيار.
- احفظ WebP واضحًا.
- ارفع إلى R2، وليس MongoDB.
- استخدم image version.
- املأ `imageUrl` و`imageAlt` و`sourceMeta.imageVersion`.

## الاختيارات

إذا كانت قيم الاختيارات مطبوعة داخل صورة السؤال:
- `options=["أ","ب","ج","د"]`
- `optionsEmbeddedInImage=true`
- املأ `aiContext.optionTexts` بالقيم الحقيقية لأ، ب، ج، د بالترتيب.

إذا لم تكن القيم داخل الصورة:
- خزّن النص الحقيقي لكل اختيار في `options`.
- `optionsEmbeddedInImage=false`.

`correctOptionIndex`: أ=0، ب=1، ج=2، د=3.

## النص والذكاء الاصطناعي

لكل سؤال املأ:

- `text`: رأس السؤال بصياغة صحيحة.
- `aiContext.readableText`: السؤال كاملًا وكل المعطيات اللازمة للفهم دون حل.
- `aiContext.speechText`: صياغة عربية طبيعية يستطيع المعلم الصوتي نطقها.
- `aiContext.visualDescription`: وصف الرسم/الجدول/الأبعاد اللازمة، دون استنتاج الحل.
- `aiContext.optionTexts`: القيم الحقيقية للاختيارات عند استخدام أ/ب/ج/د فقط.
- `aiContext.mathExpressions`: كل تعبير رياضي مهم كـLaTeX + نطق عربي.
- `aiContext.concepts`: المفاهيم الرئيسية.
- `aiContext.requiredData`: المعطيات الأساسية التي لا يجوز إسقاطها.
- `aiContext.version=1`.

مثال رياضي:
```json
{
  "latex": "\\sqrt{49}",
  "spokenArabic": "الجذر التربيعي لتسعة وأربعين"
}
```

مثال:
`7^2` يقرأ: "سبعة أس اثنين".
لا تجعل RTL يقلب الأساس والأس.

## الحل

املأ:
- `explanation`: حل صحيح كامل بعد التحقق.
- `hint`: تلميح قصير لا يكشف الإجابة مباشرة.
- `solvingStrategy`: فكرة الحل أو القانون المختصر.

لا تنسخ حلًا مشوهًا من OCR. أعد قراءة الصورة وتحقق حسابيًا.

## المهارات

استخدم فقط IDs الموجودة في:
`docs/architecture/QUESTION_BANK_V2_INGESTION_CONTRACT_AR.md`

عادة:
`skillIds=[MAIN_SKILL_ID,SUB_SKILL_ID]`

الخادم نفسه يتحقق من أن الـSubSkill موجودة فعلًا داخل الـMain Skill الحالية، ويرفض أي ID خارج taxonomy.

خطوات التصنيف:
1. عنوان الدرس/القسم يحدد المجال المرشح.
2. مضمون السؤال يحدد SubSkill.
3. تحقق من الـID والاسم من القائمة الحالية.
4. عند الشك لا تختر مهارة عشوائية؛ اجعل السؤال `draft/needs_review`.

## الفيديو

لا يلزم وجود فيديو أثناء الاستيراد الأول.

بعد تصوير الشرح، اربط الفيديو بالكود:
```json
{
  "items": [
    {
      "questionCode": "QDR-QNT-FND26-P015-Q01",
      "videoUrl": "https://youtube.com/..."
    }
  ]
}
```

Endpoint:
`PATCH /api/quizzes/questions/video-links`

لا تبحث عن السؤال برقم الصف أو اسم الصورة؛ استخدم `questionCode`.

## PowerPoint / QR لاحقًا

عند إنشاء شريحة لكل سؤال:
- ضع `questionCode` في الشريحة.
- اسم ملف/ملاحظة الشريحة يمكن أن يحمل نفس الكود.
- أي QR لاحقًا يُنشأ بالاعتماد على نفس الكود أو رابط السؤال المبني عليه.
- بذلك يمكن ربط قائمة فيديوهات كاملة آليًا دون تعديل كل سؤال يدويًا.

## Pilot إلزامي

لا تبدأ الكتاب كاملًا.

ابدأ بـ40 سؤالًا:
- 8 عمليات حسابية
- 8 كسور
- 8 أسس
- 8 جذور
- 8 مقارنة/رسومات/هندسة

لكل سؤال أعط تقريرًا:
- questionCode
- documentCode/page/questionNumber
- imageUrl
- text
- mainSkillId
- subSkillId
- correct letter/index
- aiReadableText
- speechText
- visualDescription
- mathExpressions
- validation status

لا تنتقل إلى Full Import حتى تتم مراجعة العينة.

## معيار النجاح

السؤال ناجح فقط إذا:
- الصورة كاملة وواضحة.
- يمكن فتحه في مركز الأسئلة ورؤية الصورة.
- يمكن استبدال الصورة مع بقاء نفس السؤال والكود.
- يمكن تعديل text/options/correct answer.
- المهارة الفرعية تظهر فعلًا في المحرر.
- السؤال مرتبط فقط بمهارات taxonomy الحالية.
- AI يفهم السؤال من السياق النصي دون إرسال الصورة كل مرة.
- النطق العربي للرياضيات صحيح.
- الحل متوافق مع مفتاح الإجابة أو معلّم بوضوح للمراجعة عند التعارض.
- الفيديو يمكن ربطه لاحقًا بواسطة questionCode.
