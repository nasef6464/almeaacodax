# اختبارات الباركود العامة

## الهدف

إتاحة اختبار عام يشبه نماذج Google Forms أو Microsoft Forms، لكن مرتبط بمركز الأسئلة وتحليل المهارات في المنصة. يدخل الطالب من رابط أو QR بدون تسجيل، يكتب بياناته الأساسية، يحل الاختبار، ثم تظهر نتيجة بسيطة له وتظهر لوحة تحليل كاملة للمشرف أو المدير.

## تجربة الطالب

1. يفتح الطالب رابطًا عامًا مثل `/barcode-test/{slug}` أو يمسح QR.
2. يرى عنوان الاختبار وبيانات قصيرة فقط.
3. يكتب: الاسم، المدرسة، الفصل.
4. يحل الأسئلة المسحوبة من مركز الأسئلة.
5. بعد التسليم يرى نتيجة مبسطة:
   - الدرجة.
   - أقوى مهارة.
   - أضعف مهارة.
   - نص قصير: "اعمل إيه الآن".
   - رابط دخول/إنشاء حساب لاستكمال التدريب داخل المنصة.

## إدارة المشرف

1. إنشاء اختبار باركود من لوحة الإدارة.
2. اختيار المسار، المادة، القسم، المهارات، وعدد الأسئلة من مركز الأسئلة.
3. تحديد هل النتيجة تظهر للطالب فورًا أم للمشرف فقط.
4. توليد رابط وQR قابل للطباعة أو الإرسال.
5. تحليل النتائج:
   - عدد المشاركين.
   - متوسط المدرسة/الفصل.
   - أضعف مهارات مشتركة.
   - ترتيب الطلاب حسب الاحتياج.
   - تصدير Excel/PDF.
   - تحويل طالب أو فصل إلى خطة علاج/اختبار موجه لاحقًا.

## قواعد مهمة

- لا يحتاج الطالب تسجيل دخول قبل الاختبار.
- لا يتم خلط هذه النتائج مع حساب الطالب إلا إذا سجل لاحقًا وربطنا الهوية.
- الأسئلة تأتي من مركز الأسئلة فقط.
- الاختبار له إدارة خاصة حتى لا يختلط مع اختبار ساهر أو الاختبارات الموجهة.
- الرابط العام يجب أن يكون محدود الصلاحية أو قابلًا للإيقاف.
- يجب منع تكرار التسليم العشوائي قدر الإمكان باستخدام بصمة جلسة خفيفة ورقم محاولة.

## التنفيذ المقترح

1. نموذج بيانات `PublicBarcodeTest` للإعدادات والرابط وQR.
2. نموذج بيانات `PublicBarcodeSubmission` لإجابات الطلاب وبيانات المدرسة والفصل.
3. مسارات API عامة:
   - `GET /public-tests/:slug`
   - `POST /public-tests/:slug/start`
   - `POST /public-tests/:slug/submit`
4. مسارات إدارة محمية:
   - إنشاء/تعديل/إيقاف اختبار باركود.
   - تحميل QR.
   - تقرير المشاركات والتحليل.
5. صفحة طالب عامة بسيطة.
6. تبويب إدارة خاص داخل لوحة الاختبارات أو تبويب مستقل باسم "اختبارات باركود".

## معيار النجاح

يعتبر المسار مكتملًا عندما يستطيع المشرف إنشاء اختبار من مركز الأسئلة، نشر QR، دخول طالب بدون حساب، تسليم إجابات، رؤية الطالب لتقرير مختصر، ورؤية المشرف لتحليل كامل مع تصدير.
