- توحيد عنوان الفحص إلى API الموقع الرسمي عبر Vercel، كما يفعل Post Deploy Smoke الناجح، بدل Render المباشر. كلاهما لنفس النسخة من التطبيق؛ لا تغيير للمسارات العامة أو قواعد التوجيه. هذا يصحح مسار التحقق ليمثل دخول الموقع الفعلي، ولا يثبت وحده سبب فشل الاتصال المباشر من GitHub.
