# تدريب أسئلة المراجعة الموجودة — 2026-10-10

## النطاق
طلب المالك تدريبًا من أسئلة المراجعة الموجودة كالتدريب العادي. أعيد استخدام Favorites → ReviewSession وبطاقات الأسئلة الأصلية وanswerReviewCard؛ لا إنشاء اختبار رسمي أو نسخ بنك أسئلة أو توليد أسئلة. النطاق الحالي أسئلة المحفوظة والأخطاء، بحد 20 سؤالًا للصفحة الحالية. مراجعة المادة الكاملة ليست معتمدة بهذه الأدلة.

## الفجوات المثبتة والإصلاح
- رابط التدريب كان يسقط رقم صفحة المكتبة؛ أصبح يحمل الصفحة ويستخدمها في القراءة الخاصة القائمة.
- آخر إجابة كانت تتجاوز التصحيح والشرح إلى الملخص؛ أصبحت كل إجابة تتبع اختيار → حفظ → تصحيح وشرح → التالي/الملخص.
- إعادة التدريب كانت تقرأ المكتبة المتغيرة بعد الإجابات؛ أصبحت تعيد نفس الدفعة المحملة دون طلب شبكة إضافي.
- خطأ تحميل دفعة فارغة كان يختفي خلف ملخص فارغ؛ أصبح خطأ واضحًا مع إعادة المحاولة. الاستجابات المتأخرة للتحميل والحفظ لا تغير جلسة أحدث.
- النص والاختيارات والشرح والملخص يعرضون HTML عبر أداة تنقية الأسئلة الموجودة، بدل ظهور العلامات كنص.

## الموارد والبيانات
قراءة خاصة واحدة لبدء دفعة ≤20، وكتابة الإجابة الموجودة لكل سؤال؛ إعادة الدفعة محلية. لا polling أو خدمة/قاعدة بيانات جديدة. حفظ الإجابة يستعمل المعرف الأصلي وترتيب الاختيارات الأصلي ومعرف حدث ثابت عند فشل الحفظ وإعادته. لا تغيير API أو RBAC أو خوارزمية الإتقان أو نتائج الاختبارات الرسمية. التدريب يواصل سجل المراجعة والتقدم القائم.
