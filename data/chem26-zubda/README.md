## الحدود

**لا نكرر** taxonomy، أو تدريبات الـ139، أو اختبارات الـ35، أو البنك canonical ذي الـ1708 سؤالًا. هذا المسار يضيف طبقة مفاهيم وخرائط ومراجعة جديدة فقط، ويربطها بالـIDs الموجودة.

لا استيراد مباشر إلى Atlas أو نشر تلقائي أو تعديل مجاني/مدفوع أو grading/mastery أو ربط بأسئلة canonical قبل مراجعة بشرية متخصصة.

## مواصفة المحتوى (v1)

كل `mainSkill` له: `mainSkillId`، خريطة مفاهيم/علاقات `mainMap`، هدف مركزي، روابط مهارية ومسار مراجعة.

كل `subSkill` له: `id` و`code` مطابقان للـtaxonomy، هدف تعليمي، زبدة قصيرة، شرح مترابط، خريطة فروع، نقاط امتحانية، فخاخ شائعة، مثال محلول، وأسئلة مراجعة أصلية متعددة الخيارات بإجابات مفسّرة. تمديدات الشرح الخارجة عن التلخيص المباشر تُسجل في `editorialExtensions`.

الأسئلة الجديدة **اختبارات فهم داخل محتوى القراءة فقط**، ليست أسئلة canonical، ولا تدخل بنك التقييم. الأجوبة مفاتيح للمراجعة التحريرية؛ إن نُشرت لاحقًا يجب فصلها عن الاستجابة الأولية للطالب.

## بوابات الجودة

1. تطابق معرفات وعناوين المهارات تمامًا مع المرجع المجمد.
2. دقة علمية: صحة المفاهيم والرموز الكيميائية والسبب والنتيجة، ومراجعة الاستثناءات.
3. أسلوب تعلم: شرح سببي وليس ترجمة، أمثلة أصلية وتفسير جميع الإجابات.
4. بنية صالحة للعرض: خريطة رئيسية وخريطة فرعية، واتجاه كتابة عربي متوافق مع الصيغ.
5. مراجعة حقوق المصادر: لا نقل صفحات/صور أو أسئلة كتابية حرفية.
6. تدقيق اختصاصي قبل تحويل `EDITORIAL_DRAFT` إلى `APPROVED_FOR_PUBLICATION`.
7. ربط تجريبي آمن لواجهة القراءة على فرع فقط، ثم اختبارات واجهة، ثم PR وCI قبل أي دمج.
8. التحقق بعد النشر من رحلة الطالب الفعلية قبل وصفها بأنها مكتملة في الإنتاج.

## الاستئناف في كل تشغيل آلي

1. اقرأ `AGENTS.md` وملف CHEM26 canonical وحالة PR/HEAD الفعلية أولًا.
2. اعثر على آخر دفعة وحالة اعتمادها. لا تكرر ما كُتب، ولا تعيد بنك الأسئلة أو taxonomy.
3. اختر مجموعة فرعية جديدة وافحص صفحاتها المرجعية، وأنشئ مجموعة محتوى ذات أثر حقيقي (خرائط/أمثلة/أسئلة/تدقيق).

6. إذا اكتمل هذا النطاق بكل بوابات المراجعة والنشر المطلوبة، أوقف الجدولة بدل اختراع أعمال جديدة.
